# FacilityFlow  
### Smart and Efficient College Hall Booking & Management System  
*(For PCCOE College)*

---

##  About the Project

FacilityFlow is a web-based hall booking and management system designed to digitize and simplify the process of booking college halls for academic events, seminars, workshops, and cultural programs.

The system allows students and faculty to request hall bookings online, while administrators can efficiently manage approvals, schedules, and usage reports. It eliminates manual paperwork, avoids scheduling conflicts, and ensures transparent hall allocation across the campus.

This project was developed specifically for **PCCOE College** to improve operational efficiency and resource management.

---

##  Technologies Used

### 🔹 Frontend
- **HTML** – Provides a structured and semantic layout for the application  
- **Tailwind CSS** – Utility-first CSS framework for responsive and modern UI design  
- **JavaScript (ES6+)** – Handles client-side logic, form validation, and dynamic interactions  
- **React.js** – Component-based library for building a scalable and interactive user interface  

### 🔹 Backend
- **Node.js** – Server-side runtime environment for handling application logic  
- **Express.js** – Lightweight backend framework for building RESTful APIs and routing  

### 🔹 Database & Services
- **MongoDB** – NoSQL database for storing booking data, users, and hall details  
- **Firebase** – Used for authentication and real-time features  

---

##  Key Features

- Online hall booking request system  
- Admin approval and rejection workflow  
- Real-time booking status updates  
- Automated conflict detection  
- Usage and booking reports  
- Secure authentication system
